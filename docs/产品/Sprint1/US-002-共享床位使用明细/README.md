# US-002 共享床位使用明细

## 功能概述

移动端工作台页面，提供"共享床位使用明细"入口，点击进入报表页面，展示各病区的共享床位使用情况。

## 页面说明

- **工作台首页**：展示共享床位使用明细入口卡片
- **报表页面**：支持病区名称搜索，展示病区代码、病区名称、共享床位数、剩余共享床位数

## 字段说明

| 字段 | 说明 |
|------|------|
| 病区代码 | 病区唯一标识 |
| 病区名称 | 病区中文名称 |
| 共享床位 | 该病区共享床位总数 |
| 剩余共享床位 | 当前可用的共享床位数 |

## 验收标准

- [ ] 工作台有明确入口
- [ ] 报表页支持病区名称搜索
- [ ] 列表展示4个字段
- [ ] 移动端适配
