# US-001 就诊流程闭环日志

## 功能概述

PC端管理后台，用于查看完整的就诊流程闭环日志。支持按患者姓名、身份证号、时间范围搜索就诊记录，查看每条记录的完整流程节点状态和接口调用详情。

## 流程节点（7步）

1. 患者扫码/刷卡
2. 体征上传
3. 挂号
4. 视频问诊
5. 开处方
6. 结算
7. 发药/库存扣减

## 页面说明

- **列表页**：展示就诊记录，支持搜索，三种状态（已完成/进行中/异常）
- **详情页**：左侧流程节点面板 + 右侧日志详情面板，点击节点切换右侧内容

## 验收标准

- [ ] 列表页可按姓名/身份证号搜索
- [ ] 三种状态正确展示（绿色已完成、蓝色进行中、红色异常）
- [ ] 点击节点切换右侧详情
- [ ] 每个节点展示业务数据 + 多个接口调用详情
- [ ] 异常节点展示报错信息
