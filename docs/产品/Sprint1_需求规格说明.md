## US-001 就诊流程闭环日志

### 需求描述

在健康管理员端和控制台增加就诊流程闭环查看功能。管理员可查看每位患者从扫码/刷卡到发药的完整就诊流程，包括每个环节的业务数据和接口调用详情。

### 功能要点

1. **列表页**：展示就诊记录，字段包括就诊编号、患者姓名、身份证号、就诊时间、卫生室、流程状态
2. **搜索**：支持按患者姓名、身份证号搜索
3. **状态**：已完成（绿色）、进行中（蓝色脉冲）、异常（红色）
4. **详情页**：左右布局
   - 左侧：流程节点面板，展示7个节点及其状态和时间
   - 右侧：日志详情面板，展示业务数据 + 接口调用详情
5. **流程节点**：患者扫码/刷卡 → 体征上传 → 挂号 → 视频问诊 → 开处方 → 结算 → 发药/库存扣减
6. **接口展示**：每个节点可能涉及多个接口（如挂号3个、结算5个），每个接口独立展示请求/响应详情

### 验收标准

- 列表页正确展示就诊记录，支持搜索
- 三种状态视觉区分明确
- 详情页左侧节点可点击切换
- 右侧展示业务数据表格 + 各接口调用详情
- 异常节点展示报错信息和诊断建议
- 侧边栏和顶栏固定，内容区独立滚动

## US-002 共享床位使用明细

### 需求描述

在移动端工作台增加"共享床位使用明细"入口，点击进入报表页面查看各病区共享床位使用情况。

### 功能要点

1. **工作台入口**：卡片式入口，点击进入报表
2. **报表页**：支持病区名称搜索
3. **展示字段**：病区代码、病区名称、共享床位、剩余共享床位

### 验收标准

- 工作台有明确的入口卡片
- 报表页支持按病区名称搜索
- 列表正确展示4个字段
- 移动端适配良好
